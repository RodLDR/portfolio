# Content Checklist (per project)

For each project in `_projects/`, gather and fill in:

- [ ] Summary line (1-2 sentences) in front matter (`summary:`)
- [ ] Cover image (`cover_image:` front matter, place file under `assets/images/<slug>/`)
- [ ] Tags accurate (`tags:` front matter — e.g. CAD, Electronics, Firmware, Robotics, Control-Systems)
- [ ] Overview section written
- [ ] Mechanical section: 3-5 renders, exploded view (if assembly), 1 technical drawing PDF — only if project has CAD work
- [ ] Electronics section: schematic/PCB screenshots — only if project has electronics
- [ ] Firmware/control section: short code snippet + link to GitHub repo — only if project has code
- [ ] Results section: demo video (YouTube embed, do not commit raw video files) or GIF
- [ ] Links section: GitHub repo URL, any datasheets/PDFs
- [ ] `status:` front matter changed from `draft` to `published` once content is complete

## Reminders
- Keep raw video out of the repo — embed via YouTube.
- Images: compress before committing (keep repo light); 1920px wide is plenty for renders.
- Each project should mention explicit tool names (Fusion 360 / SolidWorks / Solid Edge / KiCad / Arduino / etc.) — recruiters scan for these.
